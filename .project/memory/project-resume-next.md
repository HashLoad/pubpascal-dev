- Fluxo certo: `supabase migration repair --status applied <todas antigas>` (sincroniza histórico) → `supabase db push [--include-all se a nova for "antes" da última]`. Senha do DB no **keychain do CLI** (NÃO no `.temp/pooler-url`, que tem placeholder). Sem `psql`/`pg` no PATH (instalei `pg --no-save` uma vez).
- Coluna nova → incluir `NOTIFY pgrst, 'reload schema';` OU o `db push` recarrega o cache (recarregou nas duas vezes).
